# Excalidraw Sources

## Responsibility

Holds local, untracked Excalidraw diagrams used while developing the CIRCA lore
and interface notes.

## Structure

- `*.excalidraw.md`: editable Excalidraw documents stored as Markdown.

## Boundaries

These files are local working material and are not part of the published archive
or build. Do not commit credentials or unpublished narrative material with this
folder.
