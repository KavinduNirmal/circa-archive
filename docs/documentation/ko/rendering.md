# 렌더링 파이프라인

기록은 한 번 파싱됩니다. 문서, 텍스트 내보내기, 마크다운 다운로드가 모두 같은 결과를 읽습니다.

## 한 번의 파싱, 두 개의 렌더러

lib/markdown/pipeline.ts의 parseRecord()는 세 가지를 반환합니다. mdast 트리, YAML 메타데이터, 경고 목록입니다. HTML도, React 엘리먼트도, 문자열도 반환하지 않습니다.

화면의 문서와 내보내기는 그 트리를 공유합니다. 파서가 둘이면 서로 어긋나고, 픽션상 기록은 하나의 산출물입니다.

```ts
import { parseRecord } from "@/lib/markdown/pipeline";
import { renderText } from "@/lib/markdown/emitters/to-text";

const parsed = parseRecord({ markdown, assetBaseUrl });
const text = renderText({ markdown }).output;
```

파이프라인이 둘이 아니라 React 렌더러가 둘입니다. record-prose.tsx는 열람판을 위해 서버에서 트리를 렌더링하고, record-markdown.tsx는 같은 플러그인 목록을 워크스테이션 뷰어의 react-markdown에 넘깁니다.

## 플러그인 목록

| 플러그인                 | 하는 일                                                                  |
| ------------------------ | ------------------------------------------------------------------------ |
| `remark-frontmatter`     | YAML 헤더를 파싱하고 노드를 제거해 렌더러에 도달하지 않게 합니다.        |
| `remark-gfm`             | 표, 취소선, 자동 링크, 작업 목록.                                        |
| `normalise-redactions`   | GFM이 행을 나누기 전에 표 셀 안의 이중 파이프를 이스케이프합니다.        |
| `redaction-plugin`       | 짝을 이룬 이중 파이프를 텍스트와 인라인 코드에서 비공개 노드로 바꿉니다. |
| `image-directive-plugin` | 정렬 지시문을 도판 노드로 바꾸고, 캡션에서 정렬 단어를 제거합니다.       |
| `heading-ids-plugin`     | 각 제목에 파싱 단위로 충돌하지 않는 앵커를 부여합니다.                   |

공유 목록에 플러그인을 추가한 뒤, 모든 렌더러와 이미터가 그 노드를 처리하게 하세요. 뷰어에만 있는 변환은 파이프라인의 일부가 아닙니다.

## 경고도 콘텐츠입니다

파이프라인은 던지는 대신 결함을 모읍니다. 망가진 YAML만 파싱을 멈추고, 나머지는 그대로 렌더링됩니다.

- unmatched-redaction — 구분자가 홀수입니다. 짝이 없는 하나는 문자 그대로 남습니다.
- unknown-image-align — 정렬 단어가 left, right, full이 아닙니다.
- relative-image — 에셋 기준 URL 없이는 이미지를 해석할 수 없습니다.
- metadata-disagreement — 헤더와 본문이 다른 상태를 인쇄합니다. 의도적으로 보이게 둡니다.

경고는 엔지니어링 실패가 아니라 콘텐츠 결함입니다. 테스트 코퍼스는 일부러 자기 헤더와 다릅니다. 픽션이 자기 모순을 가진 기록에 관한 것이기 때문입니다.

## 내보내기와 비공개 처리

일반 텍스트 내보내기는 비공개를 hidden으로 고정합니다. 감춰진 단어는 문자열에 아예 없습니다. 마크다운 다운로드는 원본을 제공하며, 그 단어를 담은 유일한 사본입니다.

내보내기는 렌더링된 페이지가 아니라 작성된 마크다운에서 생성됩니다. PDF 생성은 없습니다. 기록의 .pdf 이름은 픽션에 속합니다.

> [!WARNING]
> 보류된 서류에는 다운로드가 없습니다
>
> 아카이브가 공개하지 않은 서류의 다운로드 라우트는 404를 반환합니다.

## 렌더러가 하지 않는 일

아카이브 색인이나 기록 서비스를 읽지 않습니다. 문자열을 받아 데이터를 반환합니다. 그대로 유지하세요. 같은 파싱이 테스트, 내보내기, 서버 페이지, 브라우저를 두 번째 구현 없이 감당해야 합니다.

원시 HTML 없음, HTML 주입 없음, 편집기 전용 문법 없음, 네트워크 없음. 상대 도판 경로는 호출자가 넘긴 에셋 기준으로만 해석됩니다.
