# 문서

아카이브가 어떻게 만들어지는지, 기록을 어떻게 쓰는지, 둘 중 하나를 바꾸면서 다른 하나를 깨뜨리지 않는 방법을 다룹니다. 기여자가 필요한 순서대로 아홉 페이지.

## 이 프로젝트는 무엇인가

CIRCA 아카이브는 동시에 두 가지입니다. 픽션에서는 사건 심의 및 시정 조치 위원회의 공개 얼굴입니다. 일어나서는 안 될 사건에 보고서를 접수하는 연속체입니다. 코드에서는 그 지어낸 아카이브를 영어와 한국어로 렌더링하는 Next.js 애플리케이션입니다. 서버에서 렌더링되는 열람판과 대화형 워크스테이션 프리뷰가 있습니다.

기록은 지어냈습니다. 인터페이스와 렌더러, 테스트, 이 문서는 실제 작업입니다. 회원가입, 로그인, 개인 계정 페이지는 .NET 백엔드와 PostgreSQL 데이터베이스를 사용합니다. 아카이브 기록은 로컬 예시 데이터이며 주석, 답글, 편집기 초안은 브라우저 탭 안에만 남습니다.

```brand-callout
이것은 코드 문서입니다

픽션이 아니라 저장소를 설명합니다. 아카이브 자체의 읽기 안내는 공개 아카이브의 ‘아카이브 소개’에 있습니다.
```

```brand list
- [기록 쓰기](records.md) — 헤더 필드, 섹션 규칙, 비공개 처리, 도판, 그리고 원본이 있는 위치.
- [기여하기](contributing.md) — 하나의 일관된 변경, 그것을 증명하는 검사, 검증한 내용을 밝히는 풀 리퀘스트.
```


## 두 가지 판본

하나의 원본, 세 개의 표면. 기록이나 색인 항목을 바꾸면 그 기록을 읽는 모든 곳에 반영됩니다.

- **열람판 —** /site 아래의 서버 렌더링 페이지입니다. 자바스크립트 없이 읽을 수 있고, 주석을 위한 클라이언트 아일랜드가 하나 있습니다.
- **워크스테이션 —** /desktop 아래의 클라이언트 셸입니다. 드래그 가능한 창, 다섯 개의 애플리케이션, 예시 데이터로 이루어져 있습니다.
- **프로젝트 페이지 —** /meta 아래의 랜딩 페이지, 이 문서, 그리고 프로젝트 기록입니다. 픽션 바깥에서 씁니다.

두 판본은 같은 색인 항목과 같은 마크다운 원본을 읽습니다. 어느 쪽도 콘텐츠를 소유하지 않습니다.

## 무엇이 만들어졌나

열람판과 워크스테이션은 예시 아카이브 콘텐츠를 제공합니다. 개인 계정과 세션은 연동된 인증 서비스를 사용합니다.

- **==만들어짐== —** 공개 포털, 열람판과 기록 다운로드, 워크스테이션과 다섯 개의 애플리케이션, 마크다운 파이프라인, 프로젝트 페이지, 이 문서, 그리고 계정 저장, 쿠키 세션 교체, 권한 정책, Next.js 연동을 구현한 .NET 10 인증 서비스(`backend/Circa.sln`).
- **==진행 중 / 미연동== —** 아카이브 도메인 핸들러, 기록 저장, 저장되는 주석, 발행, 중재, 해당 기능의 클라이언트 연동.
- **==계획== —** ARCHITECTURE.md에 설명된 완전한 .NET 10, EF Core, SignalR 플랫폼.

> [!WARNING]
> ARCHITECTURE.md는 초안입니다
>
> 전체 목표 플랫폼을 설명합니다. 인증 API와 스키마는 구현되어 있으며, 아카이브 도메인 계약은 초안입니다. 오늘 인터페이스가 하는 일의 기준은 실행되는 코드이며, 이 페이지들은 실행되는 코드를 문서화합니다.

## 이 문서를 읽는 법

인터페이스는 영어와 한국어로 번역되지만 코드 식별자, 라우트, 명령, 아카이브 코드는 번역되지 않습니다. 이 문서는 기본 브랜치를 따르며 버전 선택기는 없습니다. 프리프로덕션이고 트리는 움직입니다.

모든 페이지는 이전/다음 주제로 끝나고, 모든 섹션에는 앵커가 있습니다. 사이드바는 입력에 따라 걸러지고, 오른쪽 레일은 지금 읽는 페이지의 섹션을 나열합니다.

문서가 트리와 다르면 트리가 맞고, 문서가 버그입니다. [저장소에 보고하기](contributing.md)

검색은 현재 언어의 아홉 문서 제목과 마크다운 전체를 대상으로 합니다. 프로젝트 페이지에서 Ctrl+K 또는 Cmd+K를 누르면 검색으로 이동합니다. 문서 편집은 GitHub의 해당 파일을 열고, 마크다운 복사는 원문을 그대로 복사합니다. 원본은 `develop` 브랜치이며 5분마다 갱신됩니다. 문서를 불러오지 못하면 다시 시도와 원본 링크가 표시됩니다.

ChatGPT에서 열기는 원문과 URL을 참고 자료로 복사한 뒤 ChatGPT를 엽니다. 내용을 붙여넣고 질문을 추가하세요. 메시지는 자동으로 전송되지 않습니다. 본문 하단에는 GitHub 편집 링크와 확인 가능한 경우 파일의 마지막 커밋 날짜가 표시됩니다.
