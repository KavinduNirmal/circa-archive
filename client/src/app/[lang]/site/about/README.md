# Archive guide route

## Responsibility

Renders the reading guide: how to use the public archive, the classes, the
statuses, clearance, and a way to the workstation and the public portal.

## Boundaries

This is the in-world guide, not the project page. The project page is
`../../../../meta/about/` and is linked from the archive chrome as "About the
site". Copy lives in the `site` namespace.

## Usage

`/{lang}/site/about`. Covered by `tests/archive-site.test.tsx`.
